# Documentación de KACE en español

KACE es la herramienta interactiva que se ejecuta en el host Linux de la impresora para generar y desplegar configuración y firmware de Klipper. KACE Studio es la aplicación de Windows que prepara la imagen del Raspberry Pi, configura el primer arranque y entrega el bootstrap verificado de KACE.

El [README principal](../../README.md) es la fuente canónica para el estado actual, características, requisitos, instalación, arquitectura, compatibilidad, CI y roadmap del proyecto. Centralizar esa información evita que cifras, versiones o contratos de instalación queden desincronizados entre traducciones.

## Estado

KACE está en desarrollo activo previo a la versión 1.0. Los tests y matrices automatizadas no sustituyen la verificación eléctrica, mecánica y térmica de una impresora real.
