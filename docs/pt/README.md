# Documentação do KACE em português

KACE é a ferramenta interativa executada no host Linux da impressora para gerar e implantar configurações e firmware do Klipper. KACE Studio é o aplicativo Windows que prepara a imagem do Raspberry Pi, configura a primeira inicialização e entrega o bootstrap verificado do KACE.

O [README principal](../../README.md) é a fonte canônica para o estado atual, recursos, requisitos, instalação, arquitetura, compatibilidade, CI e roadmap do projeto. Centralizar essas informações evita que números, versões ou contratos de instalação fiquem dessincronizados entre traduções.

## Estado

KACE está em desenvolvimento ativo anterior à versão 1.0. Testes e matrizes automatizadas não substituem a verificação elétrica, mecânica e térmica de uma impressora real.
